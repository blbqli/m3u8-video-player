M3U8 player FAQ

What is an M3U8 file?

An M3U8 file is a UTF-8 HLS playlist that points to video segments and may contain multiple quality levels.

Why does a stream fail to play?

Common causes include CORS restrictions, an expired URL, mixed HTTP content, unsupported codecs, encryption, DRM, or referrer protection.

Does the player store my stream URL?

No. Playback happens in your browser. The source server still controls access and cross-origin permissions.
